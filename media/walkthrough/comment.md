### The loop

1. Select a passage in the rendered preview.
2. Click **+ Comment on selection**.
3. Write what's wrong with it — specifically. "This claim skips a step" beats
   "unclear".

The thread anchors to the text, not the line number, so it survives edits above
it. If the passage is deleted entirely, the thread surfaces as **broken anchor**
rather than silently re-attaching somewhere it doesn't belong.
